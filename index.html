AgentGo 6대 핵심 아키텍처

업무 자동화를 즉시 적용·관리하는 엔터프라이즈 멀티 AI 에이전트 통합 플랫폼

01 Platform (플랫폼 기반)

인프라 종속성을 탈피한 고가용성 서빙 환경

• 급격한 사용자 요청 급증 시에도 무중단 가용성 보장
• 보안이 엄격한 망분리 및 국방·공공 폐쇄망 즉시 구축

✓ 시스템 무중단 보장 · 인프라 벤더 락인 방지
1
컴퓨팅 & 서빙 아키텍처
배포 유연성
• BareMetal · Private VM · CSP Multi-Cloud 하이브리드 지원
• GPU 클러스터 가상화 분할 및 컨테이너 리소스 동적 할당
K8s / Argo vLLM Serving GPU 가상화 Harbor

03 Guard (보안 가드레일)

기업 고유 지적 자산과 개인정보 유출의 원천 차단

• 악의적 탈옥 프롬프트 및 비인가 외부 데이터 반출 사전 차단
• 환각 최소화를 위해 사내 근거 규정·사규 출처 투명 제시

✓ 보안 컴플라이언스 준수 · 사실성(Faithfulness) 검증 강화
3
다층 보안 필터링 엔진
실시간 방어
• Prompt Injection 방어 필터 및 PII 양방향 실시간 비식별화
• 벡터 임베딩 기반 사규 사실성(Faithfulness) 교차 검증 파이프라인
Injection 필터 PII 실시간 마스킹 XAI 출처 표기 감사 로그 암호화

04 Marketplace (마켓플레이스)

검증된 엔터프라이즈 AI 자산을 즉시 현업에 배포

• 개발 대기 없이 전사 임직원이 즉시 사용하는 실무 비서 제공
• 그룹웨어, ERP, 결재 등 기간계 시스템을 연결한 특화 에이전트 확장

✓ 즉시 사용 가능 · 직무별 개인화 맞춤 설정
4
에이전트 카탈로그 & 생태계
카탈로그 허브
• 사규 검색 · 메일 작성 · 일정 관리 등 기본 탑재 표준 에이전트 팩
• Host 에이전트 기반 사용자 의도 해석 및 하위 전문 에이전트 라우팅
표준 에이전트 팩 Host 라우팅 온·오프 토글 Agent Eco 확장

05 Coder (개발 도구)

자연어 프롬프트 기반의 직관적인 AI 에이전트 빌드 환경

• 코딩 전문 지식이 부족해도 업무 프로세스 기술만으로 즉시 제작
• 개발자 역량 편차 없이 사내 보안 규칙과 코딩 표준 100% 자동 유지

✓ 개발 생산성 극대화 · 사내 보안 표준 자동 적용
5
VS Code 플러그인 AI 코딩 에이전트
개발 생산성
• 툴 학습 장벽 없는 VS Code 환경 내 다중 언어 코드 자동 생성·수정
• 프로젝트 코드베이스 심층 분석, Git 통합 인라인 Diff 및 오류 자동 디버깅
VS Code 플러그인 다중 언어 지원 인라인 Diff 자동 디버깅

06 Flow (워크플로우 캔버스)

다수의 에이전트 간 유기적 협업을 시각화하는 자동화 캔버스

• 복잡한 다단계 비즈니스 로직을 블록 맞추듯 직관적으로 연결
• 데이터 처리 구간별 병목 지점을 실시간 감지하여 장애 사전 예방

✓ 노코드 오케스트레이션 · 전사 엔드투엔드(E2E) 자동화
6
노코드 워크플로우 엔진
비주얼 캔버스
• 데이터 전처리 · API 연동 · LLM 호출 · 평가 등 기본 노드 라이브러리
• 크론(Cron) 스케줄러 트리거 기반 백그라운드 파이프라인 무인 실행
Drag & Drop 노드 라이브러리 자동 스케줄러 실시간 데이터 추적
